2 · Browser extraction

Autofeeder renders each article with Playwright (falls back to HTTP when a browser engine is unavailable) and extracts clean text, links, and metadata.

No extra configuration is required. If Playwright is not installed, the engine automatically falls back to a fast HTTP fetch.

3 · LLM transform

Connect any OpenAI-compatible API. The API key is sent only to your endpoint and is never stored in the database.

4 · JSON schema contract

The schema is the hard contract every record must satisfy. Add fields manually, or let the LLM propose a schema from your prompt.

5 · Output

Validated records are written to a local CSV file or a SQLite database.
